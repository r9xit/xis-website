# XIS SENSI - Free Fire Packs

## How to Deploy on Vercel

### Option 1: Drag & Drop (Easiest)
1. Go to https://vercel.com
2. Sign up with GitHub, GitLab, or email
3. Click "Add New..." → "Project"
4. Switch to the "Upload" tab
5. Drag this entire `xissensi-website` folder into the upload zone
6. Click "Deploy"
7. Your site is live in ~30 seconds!

### Option 2: GitHub (For Easy Updates)
1. Create a new GitHub repo
2. Upload these files to the repo
3. Go to Vercel → "Add New Project"
4. Import your GitHub repo
5. Click "Deploy"
